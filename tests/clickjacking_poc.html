Clickjacking (CWE-1021) Framing Verification

This harness attempts to frame both the pre-remediation (Port 5001) and post-remediation (Port 5000) applications simultaneously.

BEFORE Fix: Vulnerable Application (Port 5001)

Missing X-Frame-Options and frame-ancestors allows UI framing / overlay attacks.

Observed Result: Application renders inside iframe (Framing Allowed).

AFTER Fix: Hardened Secure Application (Port 5000)

Enforces X-Frame-Options: DENY and CSP frame-ancestors 'none'.

Observed Result: Browser rejects embedding (Refused to display in a frame).
