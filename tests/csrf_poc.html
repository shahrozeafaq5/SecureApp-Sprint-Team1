CWE-352: Cross-Site Request Forgery (CSRF) Demonstration

Simulating an external malicious website attempting to forge state-changing requests against the victim's authenticated session.

Exploit 1: Attack against Vulnerable Server (Port 5001)

No anti-CSRF token is required. Submitting this form deletes the victim's file silently.

Exploit 2: Attack against Hardened Secure Server (Port 5000)

Protected by Synchronizer Token Pattern + SameSite Lax/Strict. The request lacks a valid session CSRF token.

Expected response: 403 Forbidden (CSRF token missing or invalid).
